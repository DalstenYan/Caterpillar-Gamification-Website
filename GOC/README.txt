Node.js installation is required

Dependencies: Run the following command in the same directory as Server.js (should be GOC) to install dependencies
npm install express mysql2 dotenv

.env example
.env contains the log in info that feeds into Server.js. For security/best-practice it has been partially redacted. The information is the same as posted in Discord.

Connect to server
Run the following command in the same directory as Server.js (should be GOC)
node server.js
